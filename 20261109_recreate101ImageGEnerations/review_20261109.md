# Implementation review

Date: 2026-11-09

| Finding | Status |
| --- | --- |
| The local API reserve cannot enforce provider charges. | Open. Strict mode blocks paid calls. Estimated-reserve mode needs user acceptance. |
| Live API model access, response usage, and cost are not verified. | Open. The user selected the Codex host tool instead. |
| The API runner cannot reconcile an uncertain request automatically. | Open. It stops and keeps the reservation. |
| The runner stops on request failures and does not retry transient failures. | Open. This keeps uncertain charges visible. |
| Configurable budget warnings are not implemented. | Open. The API runner stops when the next reserve exceeds the allowance. |
| GIF encoding checks decodability, but does not independently verify every logical frame and duration. | Open. The example GIF was checked with `ffprobe`: 11 frames, 4.25 seconds. |
| Automatic aspect-ratio selection and an explicit crop option are not implemented. | Open. The API runner pads to the selected canvas without stretching. |
| Host image calls need an agent to orchestrate them. | Open by design. The private host tool has no autonomous CLI bridge. |
| Host usage and cost were unavailable in the ten-generation test. | Recorded as unavailable. No direct API calls were made. |
| Invalid generated API bytes could be written as a committed frame. | Fixed in commit `3858f22`. |
| A host result saved before a crash could block recovery. | Fixed in commit `abef381`. |
| The API GIF could have inconsistent frame dimensions. | Fixed in commit `3858f22`. |

An independent agent reviewed the code and its findings were checked locally. Its final branch review found an empty diff against `origin/master`, because the changes had already been pushed. The project is one directory in a larger repository.
