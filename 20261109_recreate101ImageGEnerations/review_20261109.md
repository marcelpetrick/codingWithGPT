# Implementation review

Date: 2026-11-09

| Finding | Status |
| --- | --- |
| A local reserve cannot enforce the provider charge. | Open. Strict mode blocks paid requests. Estimated-reserve mode needs user acceptance. |
| Live model access, response usage, and actual cost are not verified. | Open. Run the pilot with an image and allowance. |
| The runner stops on all request failures. It does not retry transient failures. | Open. This keeps uncertain charges visible. |
| The runner does not issue configurable budget warnings. | Open. It stops before a request when the reserve exceeds the remaining allowance. |
| GIF encoding checks decodability but does not independently verify every logical frame and duration. | Open. The PNG frames remain authoritative. |
| The runner does not support explicit crop or automatic aspect-ratio selection. | Open. The user selects a canvas. The runner pads without cropping. |
| The optional host image tool adapter is not implemented. | Open. The API and mock providers are separate. |

Review method: inspected the runner, the operating reference, and the mock test results. The review is local. It is not an independent agent review.
