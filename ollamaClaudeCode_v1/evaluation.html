How to read the gates

  • nested schema — enums plus an array of objects, like a real patch tool. pick right tool — four offered; must choose search_code.
  • tools @ long ctx — tool call with ~53k tokens already in the window, run 3×. This is where models silently stop emitting tool calls.
  • deepest recall — deepest prompt, in measured tokens, from which a fact buried mid-document was still retrieved. Lower figures are window limits, not model limits: the deeper needle overflowed num_ctx and was discarded before the model saw it.
  • All gates ran with thinking disabled and a 4000-token budget. Under a squeezed budget these same models fail in ways that look like incapability — no call, wrong schema — so both must be controlled for.

Findings

  • presence_penalty 1.5 — a vendor default — costs 35% of throughput. Isolated at identical weights/ctx/VRAM: 84.4 → 129.5 tok/s at 0. temperature 0 adds no speed.
  • MTP reverses sign by architecture. +170% on the bandwidth-bound dense q8 (18.1→48.8 S) but −25% on the MoE, which was never bandwidth-starved. Not a generic optimisation.
  • A 12.5% VRAM spill costs 5.3×. Same weights at ctx60k vs ctx128k: 29.6 → 5.6 tok/s. Loads fine, passes every gate, silently five times slower.
  • Bare model tags cap at 16384 tokens through /v1/messages, which has no num_ctx knob — and tool calling stops entirely past it, with no error. Only point an agent at a ctx-baked variant.
  • Overflowing num_ctx discards half the window (num_ctx/2+2; four models, three window sizes) — but only on Ollama 0.32.5. On 0.30.6 the window fills normally, so this is a regression in the newer server.
  • temperature 1 makes small-model tool calls a coin flip. The 9b passes the nested-schema gate 4–5/8 at defaults, 8/8 at temperature 0 — so single-trial gate results below measure luck as much as capability.
  • The new server is 1.4× the old one, not the ~2× the raw quoted figures implied (identical model on both hosts). The rest was model and configuration choice.
Profile S = Sieve-of-Eratosthenes prompt capped at 300 tokens (comparable to the v0 history). Profile L = "Write exactly 1000 tokens about GPUs", uncapped (comparable to the figures quoted by Alex). The two are never averaged: longer generations amortise warm-up and report higher tok/s on identical hardware. Context ceiling = largest num_ctx whose weights+KV still sit entirely in VRAM. Recall depth is the deepest prompt, in tokens reported by the server, from which the buried fact was retrieved; prose measures 1.65 tokens/word here.
