## Why a new round
The owner needs agentic software engineering on Qt, C++ and Python, project management with GitLab, and correct summaries of long text. Correctness comes first. Speed, token cache and context size also count. The old pick rests only on a Python task and one tool-call gate.

## The rule (fixed before the data)
1. **Correctness** is the mean, over four tasks, of the median share of checks passed.
2. **Gate:** T5 must reach at least 7/8, else the model is not ranked.
3. **Ranking:** the highest correctness wins. Within 3 points, the shorter median session time wins.
4. **n:** 3 runs per task is final. 2 runs is preliminary. Below 2 is not ranked.
5. **Summary length:** an answer above 600 words scores 0. The prompt asks for 450.
   Output is capped at 8192 tokens. A model that uses them all without an answer scores 0; this is a result, not a void run.
6. **Void runs:** a spill, a reload, a foreign model, a crash or an empty answer is not a score. The run is retried once.
7. **Versions:** the auto-updater is off. A client or server version change stops the job.

Speed, cache and context are reported, and they do not enter the score except as the tie-break.
