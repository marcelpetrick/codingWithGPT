## Box constraints (what a candidate must meet)

- Ollama 0.33.3 on `.67`, driven by Claude Code via `ANTHROPIC_BASE_URL`, so Anthropic-format tool calls
- ~35.5 GB usable VRAM, **100% resident** (a spill cost 5× in v1)
- ≤ ~26 GiB of weights, so the 256k KV cache fits. In practice Q4_K_M/Q5_K_M, 17–25 GiB, never below 4-bit
- MoE with ~3B active preferred. Dense 27B has been measured 4× too slow here once
