Does /init make your AI coding agent better?

What the controlled studies say about CLAUDE.md, AGENTS.md and similar context files.
Short answer
Not reliably.
  • No controlled study found a frontier agent reliably solving more tasks with one.
  • In the ETH Zürich study it made each task 20–23% more expensive.
  • The rules in the file get followed. The codebase tour does not help.
6 controlled studies · every number checked at the source1 / 5 →
Finding 1

Your CLAUDE.md is really two different files.

Rules → followed
Name a tool in the file and the agent uses it 1.6× per task. Leave it out: under 0.01×.
Codebase tour → no help
Overviews did not help agents find the right file any faster. A summary of code answers 4 of 45 questions about what it does. The code itself answers 27.
Better writing won’t fix it: a frontier model’s summaries scored as poorly as a small 3B model’s.
Gloaguen et al., ETH Zürich, arXiv:2602.11988 · Sam-Bodden, arXiv:2607.096912 / 5 →
Finding 2 · the surprise

Random rules scored as well as expert ones.

50 → 64%
of borderline tasks solved by Claude Code (Opus 4.6) — with curated rules and with random rules alike.
The fine print
58 of 500 tasks, one run each, no single result significant. Over the full benchmark: about +1.6 points. Having a file may nudge the agent. What it says didn’t matter.
And ~9% of results flip between two identical runs. Most published numbers can’t tell a gain from luck.
Zhang et al., arXiv:2604.11088 · noise: Sam-Bodden, arXiv:2607.096913 / 5 →
Finding 3

What measurably helped: writing down the agent’s mistakes.

25.5 → 33%
of tasks solved, after the guidance file was tuned against the agent’s own failures. Four repeated trials, p < 0.001.
The fine print
It helped the agent find the right file, not write better fixes. And it was an open 35B model, not Claude or Codex — nobody has tried it on a frontier agent yet.
Shepard & Albrecht, arXiv:2606.20512 · SWE-bench Verified4 / 5 →
