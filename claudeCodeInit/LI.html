The headline

Your context file is two things. They have opposite signs.

Followed
Instructions work. Name a tool in the file and the agent uses it 1.6× per task, versus under 0.01× when unmentioned.
Ignored
Repository overviews do not. The architecture tour /init writes did not help agents find files any faster — and cost 20–23% more inference.
Read the effect sizes with care: ~9% of outcomes flip between byte-identical runs at temperature zero. Most published effects sit inside that noise.
