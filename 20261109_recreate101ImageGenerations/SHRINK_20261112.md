## Plan

1. Back up: `git bundle create` of all refs plus a `tar` of the original frames (outside the repo).
2. Install `git-filter-repo` (`pacman -S git-filter-repo`).
3. Convert: write the new GIFs and frames into the work tree; delete `checkpoints/`.
4. Update `recreate-101/scripts/*.mjs` and the generators for the new file names; run the tests.
5. Regenerate the per-chain `README.md` and the comparison from the data.
6. Rewrite history: remove `*/checkpoints/*.gif`, `*/frames/*.png` and `*/evolution.gif` from all commits,
   under both directory names (`20261109_recreate101ImageGenerations`, `20261109_recreate101ImageGEnerations`).
7. Commit the converted files as one new commit on top.
8. Verify: blob sizes, `git fsck`, tests, compare the text files with the backup.
9. Ask the owner, then `git push --force-with-lease origin master`.
10. Check the GitHub Pages run (Liquid trap) and the repo size.

Note: GitHub keeps the old objects until its own garbage collection runs. The repo size on GitHub
can stay high for some time. A support request "gc the repo" removes them.
