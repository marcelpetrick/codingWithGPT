## Lesson

`git filter-repo` 2.47 strips GPG signatures. 74 commits on GitHub are signed (web commits), and the
root commit is one of them. A rewrite over all refs therefore changes every hash, also of untouched
commits. Limit the rewrite to the commits that contain the files: `--refs master ^<base>`.
