5 · Decision rule (fixed before any data)

"Clearly faster"

Median ≥ 25 % higher and min–max ranges that do not overlap, with n ≥ 5 per arm. Anything else is a tie.

"Really better"

Clearly faster on every workload-B cell and not worse on quality: C pass counts within 2 of 20.

6 · Confounds and their controls

RiskControl
Ollama tags ship presence_penalty 1.5, which costs about 35 % speedThe sampler is set explicitly in every request: greedy, all penalties 0
Thinking on in one engine onlyThinking off on both. A row with reasoning tokens is a failed row.
Prefix cache makes repeat runs fastEach request starts with a unique nonce
Both engines on the GPU at the same timeUnload the other engine first, record the VRAM in use in every row
Magnitude server mode updates itselfThe engine version is in every row. Rows of two versions never pool.
The drafter, not the engine, makes the speedThe nodraft / plain arms
A failure booked as a slow resultErrors, empty answers and timeouts are failed rows. An unreachable engine stops the run.
