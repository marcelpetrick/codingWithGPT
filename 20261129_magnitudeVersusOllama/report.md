## Arms

- `ollama-mtp`: Ollama with the official MTP tag. This matches the vendor's Ollama arm (drafter that ships with the tag). Greedy, no penalties, thinking off.
- `ollama-plain`: Ollama without a drafter, the plain Q4_K_M tag. It shows what the MTP drafter adds. Greedy, no penalties, thinking off.
- `magnitude-default`: Magnitude with its catalog Qwen3.5 4B Q4 and its default DFlash drafter. This is the vendor's Magnitude arm.
- `magnitude-nodraft`: Magnitude with the drafter turned off. It isolates the kernel tuning from the speculative decoding.
- `magnitude-gemma-e2b`: Magnitude, Gemma 4 E2B QAT Q4 from its catalog, default MTP drafter. This is the vendor's Magnitude arm for this model.
- `ollama-gemma-e2b`: Ollama, Gemma 4 E2B QAT tag. Ollama has no MTP tag for E2B, so this arm runs without a drafter. Greedy, no penalties, thinking off.
- `magnitude-qwen2b`: Magnitude, Qwen3.5 2B Q4_K_M from Hugging Face (unsloth). Magnitude offers no drafter for this model, so this is the pure engine.
- `ollama-qwen2b`: Ollama, plain qwen3.5:2b-q4_K_M tag, no drafter. The clean engine-against-engine match for magnitude-qwen2b.
- `ollama-qwen2b-mtp`: Ollama, qwen3.5:2b-mtp-q4_K_M with its built-in MTP drafter. Shows what Ollama gets from its own drafter.
- `magnitude-gemma-e4b`: Magnitude, Gemma 4 E4B QAT Q4 from its catalog with the MTP drafter. Magnitude rates it 'Snug (8 GB)': the model that fills this GPU.
- `ollama-gemma-e4b`: Ollama, Gemma 4 E4B QAT tag (6.1 GB). Ollama has no MTP tag for E4B, so this arm runs without a drafter.

## Columns

- `site`: Where the run happened. 'laptop' is the RTX A2000 8 GB. 'box' is 192.168.100.67.
- `workload`: A = vendor replication (repeat a passage). B = realistic coding (new code). C = quality (20 tasks with unit tests). V = vision (5 generated images with known answers).
- `family`: The model family (from arms.json). Pairs only form inside one family.
- `ctx`: Context size of the cell in tokens. The prompt fills it minus the output room.
- `arm`: The labelled configuration (engine, model tag, drafter). Arms never pool.
- `engine_version`: Engine version recorded in each row of this cell.
- `n`: Good rows / failed rows. A failed row is an error, an empty answer or thinking that was not off. Failed rows never count as speed.
- `decode`: Median generated tokens per second after the first token, client side, with the min-max range. Higher is better.
- `prefill`: Median prompt tokens per second up to the first visible token, client side (includes HTTP and scheduling). Higher is better.
- `ttft`: Median time to the first visible token in seconds. Lower is better.
- `passed`: Workloads C and V: tasks that passed (unit tests for C, expected keywords for V; greedy).
- `pair`: Arm a against arm b in the same cell of the same model family.
- `decode_ratio`: Median decode of a divided by median decode of b.
- `decode_verdict`: Fixed rule: 'faster' needs a median at least 25% higher and min-max ranges that do not overlap, with n >= 5 per arm. Else 'tie'.
- `prefill_ratio`: Median prefill of a divided by median prefill of b.
- `prefill_verdict`: Same fixed rule as decode_verdict, on prefill.
- `status`: Gate result: does the model load and answer at all on this site.
