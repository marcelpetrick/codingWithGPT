Verdict

  • Yes, stable has slowed down. The usual rhythm is one update every ~2 weeks, in irregular waves.
  • The cause is Manjaro, not Linux or Arch. Arch builds more packages than usual right now.
  • Reasons given: the Forgejo move, a slow GitLab, and a maintainer with "super limited time".
  • Expect a large next update: Plasma 6.8 (SDDM → plasma-login-manager), systemd 262, kernel 7.2/7.3.
  • Action: linux71 is end of life since 7.1.13. Move to linux72 or keep linux618 (LTS).

Measure it yourself

  1. Read the stable announcements: forum.manjaro.org/c/announcements/stable-updates/12.rss
  2. Check the date of the last branch change: curl -s https://mirror.init7.net/manjaro/stable/state
  3. Compare branch versions: ./measure_branch_lag.sh
  4. Count your own update waves: ./measure_local_waves.sh
  5. Rebuild this page: python3 make_onepager.py
The state date also changes for small security pushes. It is not proof of a full update.
